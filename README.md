# 周报小工具 WeekRepo

> 一款免费的 Windows 桌面效率工具：按真实工作日提醒你记录工作，一键生成、AI 优化并归档你的周报；内置待办清单、备忘便签与年历总览，日常日程管理一站搞定。
>
> 本仓库仅用于**发布版本**（[Releases](https://github.com/KatouRyuuji/WeekRepo/releases)），项目暂不开源。

## 下载安装

1. 前往 [Releases 页面](https://github.com/KatouRyuuji/WeekRepo/releases/latest)，下载最新的 `WeekRepo.exe`。
2. 双击运行即可，**无需安装、无需 Python 环境**（单文件绿色版）。
3. 首次运行时 Windows SmartScreen 可能提示"未知发布者"，点击「更多信息 → 仍要运行」即可。

> 系统要求：Windows 10 / 11。

## 功能一览

- **首页工作台**：启动进入首页，集中处理今日待办、进度、日报和备忘。
- **跟随真实工作日**：按中国法定节假日与调休安排判断工作日，节假日绝不打扰。
- **智能定时提醒**：每周首个工作日提醒填写周计划，工作日晚间提醒记录日报，最后一个工作日提醒确认本周总结；错过提醒会延迟再提醒。
- **一键格式化导出**：自动生成规范的 Markdown 周报，连同配图按周归档到「周报 (起始日期 ~ 结束日期)」文件夹。
- **一键 AI 优化**：内置精调提示词，自动分类归纳、提升专业度，生成适合直接汇报的版本；当日日报也可一键按汇报口径优化。
- **AI 技能**：选技能与日期生成草稿，审阅后复制、存为备忘或更新日报。
- **一键直达报告**：工作区可一键打开本周周报（未导出会自动导出）、打开 AI 汇报版报告（未优化会自动优化）、打开本周周报文件夹。
- **周报配图**：为每周上传配图，与周报统一归档；日报与备忘也可贴图。
- **待办清单**：回车快速添加，支持优先级与截止日期；过期/今天到期醒目提示，拖拽排序、归档与恢复，已完成自动折叠，未完成数常显在侧边栏角标；可一键把完成的待办插入当天日报。
- **备忘便签**：卡片式随手记，支持置顶、颜色标记、全文搜索、拖拽排序与归档。
- **年历总览**：全年节假日「休」与调休「班」一屏尽览；每天的记录足迹与待办到期直观标记，点击任意日期直达当日记录。
- **番茄钟**：专注 / 短休 / 长休循环，切视图后计时继续。
- **命令面板（Ctrl+K）**：快捷命令与跨待办/备忘/日报搜索；`Ctrl+0` 回首页，`Ctrl+1~6` 切业务视图。
- **桌面小组件**：待办与备忘可钉在独立小窗。
- **8 套命名色板 × 亮/暗双模式**：霜靛 / 藤色 / 柳染 / 水浅葱 / 樱花（纸感书写）与素墨 / 海军冰蓝 / 铁锈（仪器），对比度机检锁定，侧边栏一键切换深色/明亮；界面组件（按钮/弹窗/命令面板等）与色板同源，观感统一。
- **系统托盘常驻**：双击托盘图标唤回窗口。
- **单实例运行**：重复启动会自动唤出已打开的窗口，不会开出第二份。
- **自动更新**：每次启动自动检查本仓库的最新版本，一键完成更新。
- **一键数据备份**：全部记录与设置导出为带时间戳的 JSON 备份（不含 AI token）。
- **AI Agent 自动化**：同一个 `WeekRepo.exe` 内置 CLI 与 MCP 服务，Claude Code 等 AI 助手可直接读写你的工作记录（见下文）。

## AI 优化怎么启用？

在应用「设置 → AI 配置」中填写任意兼容 Anthropic Messages 协议的服务地址、Token 与模型名即可。

## 让 AI 助手帮你写日报（CLI / MCP）

`WeekRepo.exe` 除桌面界面外，还提供命令行、终端界面与 MCP 服务，与桌面版共享同一份数据：

```bash
WeekRepo.exe --cli today --json          # 今日上下文：日报、待办、备忘、进度
WeekRepo.exe --cli todo add "核对本周进度" --due 2026-10-09
WeekRepo.exe --cli daily save --content "今日进展"
WeekRepo.exe --cli report export         # 导出本周周报
WeekRepo.exe --tui                       # 终端界面
```

CLI 共十四个命令，覆盖日报、周计划/总结、周报导出、待办、备忘、配图、年历、番茄钟、小组件、设置与备份；终端中输出易读文本，加 `--json` 输出 JSON。

在支持 MCP 的客户端（Claude Code、Cursor 等）中添加本地服务器，即可让 AI 使用全部 36 个业务工具：

```json
{
  "mcpServers": {
    "weekrepo": {
      "command": "D:/Apps/WeekRepo/WeekRepo.exe",
      "args": ["--mcp"]
    }
  }
}
```

将 `command` 替换为 `WeekRepo.exe` 的实际绝对路径。自动更新后文件名不变，配置无需修改。

## 自动更新说明

应用每次启动会静默检查本仓库的最新 Release：

- 检测到新版本时会弹窗询问是否自动更新，确认后自动下载、校验并重启完成替换；
- 如你的网络访问 GitHub 不佳，可随时手动到 [Releases](https://github.com/KatouRyuuji/WeekRepo/releases/latest) 下载最新版覆盖旧文件即可；
- 你的所有数据与设置都保存在本机用户目录（见下），**更新/覆盖 exe 不会丢失任何数据**。

## 数据保存在哪里？

- 记录与设置：`C:\Users\<用户名>\AppData\Local\WeeklyReportTool\data`
- 导出的周报与配图：`文档\WeeklyReports`（可在「设置」中修改）

## 常见问题

**Q：关闭窗口后程序去哪了？**
A：默认最小化到系统托盘继续按时提醒，双击托盘图标即可唤回；关闭时也可以选择「直接退出」。

**Q：提醒没有弹出？**
A：请确认程序在运行（系统托盘有图标）。程序会自动联网同步最新节假日安排，离线时使用内置数据。

**Q：杀毒软件 / SmartScreen 报警？**
A：单文件 PyInstaller 程序的常见误报。程序不含任何恶意行为，介意可在 Releases 页核对文件大小与 sha256 摘要后放行。

**Q：如何反馈问题或建议？**
A：欢迎在本仓库提 [Issue](https://github.com/KatouRyuuji/WeekRepo/issues)，或到 B 站私信作者。
